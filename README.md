# МАША — Структура проекта под VS Code (по архитектуре Amnesia)

Проект работает без сборщиков (чистые ES-модули): открываешь папку `masha-vn-mvp` в VS Code, правишь нужную сцену в `scripts/story/...` или заменяешь картинку/видео в `assets/...` и обновляешь страницу.

## 1. Скрипты сцен (`scripts/` — 1 сцена = 1 файл)

```text
scripts/
├── story/
│   ├── index.js                         # Реестр сборки всех сцен
│   ├── chapter_1_intro/                 # Глава 1 (Пролог)
│   │   ├── intro_1.js                   # Сцена 1: Интернат, крестик Кати, звонок Маше
│   │   ├── intro_2.js                   # Сцена 2: Троллейбус, флешбэк и фантазии
│   │   ├── intro_3.js                   # Сцена 3: Малая Бронная, ловушка про Сочи и кофейня
│   │   ├── intro_4.js                   # Сцена 4: Ночной Porsche и вход в пентхаус
│   │   ├── intro_5.js                   # Сцена 5: 01:42 ночи — окно и расклад на 4 Королев
│   │   └── intro_6.js                   # Сцена 6: Утренний душ, полотенце и домофон Ленки
│   ├── chapter_2_penthouse/             # Глава 2 («Чужой дом»)
│   │   ├── ch2_1.js                     # Сцена 1: Визит Ленки и срочный отъезд Маши
│   │   ├── ch2_2.js                     # Сцена 2: Наедине с Ленкой — намёки про «ЭТОТ дом»
│   │   ├── ch2_3.js                     # Сцена 3: Утренняя разминка ГГ у окна
│   │   ├── ch2_4.js                     # Сцена 4: Провокация и сближение на диване
│   │   ├── ch2_5.js                     # Сцена 5: Возвращение Маши и обвинение Ленки
│   │   └── ch2_6.js                     # Сцена 6: Проверка доверия и уход ГГ
│   └── chapter_3_arbat/                 # Глава 3 («Стрелки назад»)
│       ├── ch3_1.js                     # Сцена 1: Одинокая набережная и звонок Кати
│       ├── ch3_2.js                     # Сцена 2: Парк Горького — преображение Кати
│       ├── ch3_3.js                     # Сцена 3: Кленовая аллея и блеск на губах
│       ├── ch3_4.js                     # Сцена 4: Архив 2014 и двойное дно часов отца
│       └── ch3_5.js                     # Сцена 5: Поцелуй у метро и клиффхэнгер на Арбате
└── sandbox/
    └── penthouse_free_roam.js           # Песочница 4 комнат, предметы, улики и чаты iPhone
```

## 2. Графика и анимации (`assets/`)

```text
assets/
├── characters/{mc,masha,katya,lenka}/   # Листы эмоций и круглые аватарки диалогов
├── sprites/{masha,katya,lenka}/         # Прозрачные спрайты эмоций
├── locations/                           # Чистые фоны локаций (4 времени суток для пентхауса)
├── story/{intro_1..intro_6,ch2,ch3}/    # Сюжетные CG-кадры по сценам
├── items/                               # Крупные планы улик и предметы песочницы
├── ui/                                  # Обложка меню
└── videos/{loops,oneshots}/             # Анимации (.webm / .mp4)
```

## 3. Локальный запуск
```bash
python3 -m http.server 8768 --bind 127.0.0.1
```
Открыть в браузере: http://127.0.0.1:8768/
